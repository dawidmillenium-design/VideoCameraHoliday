## 4️⃣ Recommendations (prioritized)

### P0 — Decide the fate of `generated-content/` (135+ pages)
Check Search Console for impressions on `/generated-content/` URLs, then pick one:
- **~0 impressions (likely) → noindex or delete.** Add `<meta name="robots" content="noindex, follow">` + remove from `sitemap.xml`, or `git rm` them. Thin, orphaned, machine-translated pages with no hreflang are a soft-duplicate/crawl-budget liability, not an asset.
- **Real traffic → promote them properly:** inject the site shell (nav/footer/author box/JSON-LD), add `hreflang` alternates + self-canonical per locale, 5+ internal links each (English original, category hub, 2–3 related comparisons), regenerate titles/meta within length limits, strip inline styles.
- **Do not leave them as-is** — they're your biggest score drag and your biggest SEO risk in one.

### P1 — Bulk-fix EEAT on shell-less real pages (60.7% → target 80+)
The `best-cameras-northern-lights.html` pattern (no author, no dates, no JSON-LD) is scriptable:
1. Find all offenders locally: `grep -L "author-box" guides/*.html destinations/*.html reviews/*.html how-to/*.html`
2. Inject the standard author-box block + `datePublished`/`dateModified` in JSON-LD + About link into each (same snippet your good pages use).
3. Add breadcrumbs + a related-articles grid to any page with <10 internal links (fixes both EEAT-adjacent trust and the Links score).

### P2 — HTML quality sweep on survivors
- Move inline styles to classes (worst offenders: 53, 31, 20, 15 inline styles per page).
- Add missing `<h1>`/headings and wrap content in `<main>`/`<article>` on any page flagged "No headings / Poor semantic HTML".

### P3 — Upgrade the audit so generated pages can't hide real problems
The worst-30 is fully consumed by generated-content, so you can't see your worst *real* pages. Add a per-section breakdown + orphan list to `generate_report()`:

```python
def section_of(path):
    parts = [p for p in path.replace('\\', '/').split('/') if p not in ('.', '')]
    if not parts:            return '(root)'
    if parts[0] == 'generated-content': return 'generated-content'
    return parts[0] if len(parts) > 1 else '(root)'

# inside generate_report(), after the Summary block:
sections = {}
for r in valid:
    sections.setdefault(section_of(r['file']), []).append(r)

out.append("## 🗂️ Averages by Section\n")
out.append("| Section | Pages | Overall | SEO | EEAT | Links | HTML |")
out.append("|---|---|---|---|---|---|---|")
for name, rs in sorted(sections.items(),
                       key=lambda kv: sum(x['overall'] for x in kv[1]) / len(kv[1])):
    n = len(rs)
    a = lambda k: sum(x['overall'] if k == 'overall' else x[k]['pct'] for x in rs) / n
    out.append(f"| {name} | {n} | {a('overall'):.1f} | {a('seo'):.1f} | "
               f"{a('eeat'):.1f} | {a('internal_links'):.1f} | {a('html_quality'):.1f} |")
out.append("")

orphans = [r['file'] for r in valid if r['internal_links']['score'] == 0]
if orphans:
    out.append(f"## 🕳️ Orphan Pages (0 internal links): {len(orphans)}\n")
    out.extend(f"- `{o}`" for o in orphans[:50])
    out.append("")
```

Now you'll see e.g. `destinations | 48 | 78.2 | …` next to `generated-content | 150 | 47.1 | …`, and the orphan list becomes your exact P1 work queue.
