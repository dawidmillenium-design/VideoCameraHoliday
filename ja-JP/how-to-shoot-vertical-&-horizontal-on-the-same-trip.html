同じ旅行で縦動画と横動画を両方撮る方法：完全ステップバイステップガイド

こんにちは、旅行写真・動画コンテンツ専門ライターの佐藤です。年間50本以上の旅行動画を撮影し、TikTok・YouTube・Instagramの3媒体を同時運用しています。京都の竹林や沖縄のビーチ、北海道の雪原まで、日本各地で「縦も横も同じ旅で撮る」撮影スタイルを5年以上続けてきました。

この記事では、1回の旅行で縦動画（9:16）と横動画（16:9）を効率よく撮影する方法を、機材選びから撮影手順、トラブル対処まで完全解説します。「縦に撮ったのに横用に使えない」「両方撮ったら時間が足りない」という悩みを、この記事を読めば解決できます。

なぜ縦と横を両方撮る必要があるのか

2024年現在、動画プラットフォームごとに最適なアスペクト比は異なります。

  • 縦動画（9:16）：TikTok、Instagramリール、YouTubeショート
  • 横動画（16:9）：YouTube本編、テレビ、ブログ埋め込み

私が京都・嵐山で撮影した竹林の動画は、縦で撮ったものをTikTokに投稿して120万回再生、横で撮ったものをYouTubeに投稿して8万回再生されました。同じ場所・同じ時間でも、縦横それぞれに価値があるのです。

事前準備：必要な機材と設定

おすすめ機材（日本で購入可能）

  1. スマートフォン：iPhone 15 Pro以上、またはGoogle Pixel 8 Pro。4K/60fps撮影が可能で、手ぶれ補正が優秀です。
  2. ジンバル：DJI Osmo Mobile 6（約19,800円）。縦横の切り替えがワンタッチでできるため、今回の撮影に最適です。
  3. 三脚：Manfrotto コンパクト三脚（約8,000円）。雲台が90度回転するものを選びましょう。
  4. 予備バッテリー・SDカード：4K動画は1分で約400MB消費します。128GB以上のカードとモバイルバッテリーを必ず携帯してください。
  5. レンズクロス：日本は湿度が高いため、レンズの曇り対策に必須です。

撮影前の設定チェック

  1. 解像度を4K/30fpsに統一する（縦横どちらも同じ設定にすることで編集が楽になります）
  2. 手ぶれ補正をオンにする
  3. グリッド線を表示する（構図の基準になります）
  4. 露出とフォーカスをロックする（縦横切り替え時の明るさ変化を防ぐ）

縦横同時撮影のステップバイステップガイド

ステップ1：撮影計画を立てる（旅行前日まで）

  1. 訪れる場所をリストアップし、それぞれで「縦向きが映える構図」と「横向きが映える構図」をメモします。例えば、東京スカイツリーは縦で高さを強調、横で周囲の街並みを広く捉えます。
  2. 1日の撮影スケジュールを「午前＝横動画メイン」「午後＝縦動画メイン」のように時間帯で分けると効率的です。
  3. 各スポットでの滞在時間を通常の1.5倍で見積もります。両方撮るとどうしても時間がかかります。

ステップ2：横動画を先に撮る

  1. 三脚またはジンバルを横向きにセットします。
  2. 広角で全体を捉え、ゆっくり5秒間固定撮影します（編集で使いやすい尺です）。
  3. パン（左右に振る）やチルト（上下に振る）の動きを加える場合は、一定の速度で10秒かけて動かします。
  4. 被写体に近づいて细节を撮る場合は、横位置のまま寄ります。
  5. 1カットにつき3テイク撮影します（失敗に備えて）。

私の経験では、横動画は「情報量」を重視します。京都の伏見稲荷大社では、千本鳥居のトンネル全体を横で捉えることで、圧倒的なスケール感が伝わります。

ステップ3：同じ場所で縦動画を撮る

  1. ジンバルを縦向きに切り替えます（DJI Osmo Mobile 6ならボタン1つで完了）。
  2. 被写体を画面の下1/3に配置します（縦動画は上に空間があると見やすい）。
  3. 横で撮った構図を参考にしつつ、縦ならではの奥行きを意識します。例えば、横で撮った滝を縦で撮る場合は、上から下への流れを強調します。
  4. 手ぶれ補正を最大にし、両手でしっかりホールドします。縦は横より手ぶれが目立ちます。
  5. 縦動画は15秒以内のカットを意識して撮ります（SNSの短尺フォーマットに合わせる）。

沖縄の美ら海水族館では、横でジンベエザメの遊泳を広く撮り、縦で水槽の高さと光の筋を強調しました。同じ被写体でも全く異なる魅力が引き出せます。

ステップ4：移動中も両方撮る

  1. 新幹線や電車内では、窓際の席を確保します。
  2. 横で流れる景色を撮影します（1/60秒のシャッタースピードで流し撮り）。
  3. 縦で窓枠と景色のコントラストを撮影します。
  4. 駅に停車するたびに、ホームの看板や人々を両方の向きで撮ります。

ステップ5：食事シーンでの応用

  1. 横でテーブル全体を撮影します（料理の配置がわかります）。
  2. 縦で料理のアップを撮影します（湯気や質感を強調）。
  3. 箸で持ち上げる瞬間を縦でスローモーション撮影します（120fps推奨）。
  4. 食べる表情を横で撮影します（会話の雰囲気が伝わります）。

よくある失敗とトラブルシューティング

失敗1：縦横の切り替えに時間がかかる

解決策：ジンバルを使わない場合は、スマホを回転させるだけで切り替えられるマグネット式のスマホホルダー（例：Peak Design Mobile Tripod）を活用しましょう。私はこれで切り替え時間を30秒から5秒に短縮できました。

失敗2：縦動画の画角が狭すぎる

解決策：縦動画は横動画の約40%しか画角がありません。被写体から1.5倍離れて撮影するか、広角レンズ（0.5x）を使いましょう。京都の金閣寺では、横で全体を撮った後、縦では池の反射を含めて撮ることで狭さをカバーしました。

失敗3：編集時に音声がずれる

解決策：縦横を別々に撮影すると、環境音が途切れます。外部マイク（例：RODE Wireless GO II）を使い、常に録音しっぱなしにしましょう。私はこれで編集時の音声同期の手間が半減しました。

失敗4：バッテリーが足りない

解決策：4K動画はスマホのバッテリーを1時間で約50%消費します。モバイルバッテリー（Anker 737など）を必ず携帯し、撮影しないときは機内モードにしましょう。

失敗5：SDカードの容量不足

解決策：256GBのカードを2枚持参し、毎晩ホテルでバックアップを取ります。私は北海道旅行で512GBを使い切り、コンビニで急遽購入した経験があります。

日本ならではの撮影スポット別アドバイス

  • 京都・清水寺：横で舞台からの眺め、縦で朱色の柱と屋根のラインを撮影。
  • 東京・渋谷スクランブル交差点：横で人混みの流れ、縦でビル群の高さを強調。
  • 大阪・道頓堀：横でグリコ看板と川、縦で看板のアップとネオン。
  • 広島・厳島神社：横で海上の鳥居全体、縦で鳥居と空のコントラスト。
  • 北海道・富良野：横でラベンダー畑の広がり、縦で花と空の境界線。

編集時のポイント

  1. 縦横のクリップを別々のフォルダに分けて管理します。
  2. 縦動画はテロップを上部に、横動画は下部に配置します。
  3. BGMは縦横で同じ曲を使うと、シリーズ感が出ます。
  4. 書き出し設定は、縦は1080×1920、横は1920×1080で統一します。

まとめ：1回の旅行で2倍のコンテンツを

縦横同時撮影のコツは、「計画→横→縦→移動中→食事」の順番を習慣化することです。最初は戸惑うかもしれませんが、私も最初の3回の旅行では失敗ばかりでした。しかし、この手順を守るようになってから、1回の旅行で撮れるコンテンツ量が約2.3倍に増えました。

大切なのは、完璧を目指さないことです。縦横どちらかが失敗しても、もう片方が残れば大丈夫。まずは近所の公園や駅で練習し、次の旅行で実践してみてください。あなたの旅が、より多くの人に届くコンテンツになりますように。
